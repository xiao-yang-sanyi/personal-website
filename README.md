# Personal Academic Portfolio — Yanggongjie Xiao (肖阳功杰)

Personal academic portfolio website of **Yanggongjie Xiao (肖阳功杰)**, Ph.D. Candidate in Construction Management & Intelligence (CMI) at The Hong Kong Polytechnic University.

## Overview

A bilingual (中文 / English) single-page academic portfolio covering:

- **Research framework** — intelligent quality management for prefabricated construction, built on an end-to-end *assess → predict → inspect* pipeline:
  - Module 1 · Quality Assessment — ontology-driven multimodal fusion + BP‑AdaBoost
  - Module 2 · Quality Prediction — TQM-grounded dual-stream BP‑LSTM
  - Module 3 · Intelligent Inspection — Unitree B2 quadruped robot + improved YOLOv8 (EFPN)
- **Publications & projects** — journal papers, conference papers, patents, and research projects
- **Skills** — ML/DL, computer vision, knowledge engineering (ontology/semantic web), robotics, BIM
- **Research visuals** — gallery of framework diagrams, methods, and results (click to enlarge)
